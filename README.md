# 🎉 Pop-Up Message  

A simple and customizable **Pop-Up Message** component built using **HTML, CSS, and JavaScript**. This project allows you to display alerts, confirmations, or notifications in a stylish pop-up format.  

## 🌟 Features  
✅ Customizable pop-up message ✏️  
✅ Smooth animations for better user experience 🎨  
✅ Close button to dismiss the pop-up ❌  
✅ Different pop-up types (success, warning, error, info) ⚠️  
✅ Auto-hide after a set duration (optional) ⏳  

## 🛠️ Technologies Used  
- **HTML** – For structuring the pop-up  
- **CSS** – For styling and animations  
- **JavaScript** – For dynamic functionality  

## 🚀 How to Use  
1. Clone the repository:  
   ```bash
   git clone https://github.com/Fatima-progmmer/pop-up-message.git
   ```  
2. Open `index.html` in your browser.  
3. Customize the pop-up text, duration, and style in the JavaScript file.
